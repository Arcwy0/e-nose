# data/ — Training data + generated plots

Only this documentation and the directory placeholder are currently tracked.
Experimental CSVs, including local reference files, are not supplied by a clone
or wheel. Obtain approved data privately; never assume a local filename is
available to colleagues.

## What's ignored

- `data/*.csv` — put your own
  training logs here; they stay local unless you explicitly `git add -f`.
- Generated plots — regenerated by `/smell/visualize_data` on demand.
- `database_robodog*.csv` at the repo root — accumulated training log
  written by `save_training_samples`.

Share datasets through approved private storage. Do not force-add chemical
recordings or images to the public repository as an installation workaround.

Canonical training input needs verified R1–R17 values and labels. Environmental
columns are optional. Supplier exports use `timestamp_iso` and `rs_ch*_ohm`;
they contain resistances, not raw ADC codes. Unlabelled preview/replay works,
but training requires verified labels or row annotations. Heater temperature
is diagnostic, not ambient `T`. See [PCB acquisition](../docs/PCB_ACQUISITION.md)
and [training](../docs/MODEL_IMPROVEMENTS.md).

Root `database_robodog.csv` is active canonical training history. Migrate it
with the matching classifier/candidate snapshots, not just files in `data/`.
